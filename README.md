# 🛒 E-Commerce Pulse — Sales & Returns Analytics Dashboard
---

## 📌 Project Overview

**E-Commerce Pulse** is a multi-page interactive Power BI dashboard that transforms raw e-commerce sales and returns data into compelling, actionable insights. Covering **150 total orders** across **9 product categories**, **4 regions**, and **5 payment methods**, this project simulates a real-world retail analytics use case — exploring revenue trends, return behavior, payment preferences, and category-level performance through rich visual storytelling.

---

## 📊 Dashboard Pages

### Page 1 — E-Commerce Dashboard (Sales Overview)
A high-level snapshot of business-wide KPIs including Total Revenue, Total Orders, Average Order Value, and Return Rate — with slicers for Month, Category, and Region filters. Features a revenue trend line chart by month, category-wise revenue bar chart, and payment method donut chart.

![E-Commerce Dashboard](E-Commerce%20Dashboard.png)

---

### Page 2 — Returns & Sales KPI
Deep-dive into return analytics including Return Rate, Revenue Lost to returns, Top Return Category, and Total Returns count. Features category-wise return count bar chart, monthly return trend, payment method revenue breakdown, and a detailed order-level table with Product, Category, Revenue, and SalesRep.

![Returns & Sales KPI](Returns%20%26%20Sales%20KPI.png)

## ✅ Final Conclusion

The **E-Commerce Pulse Dashboard** reveals clear patterns in how revenue, returns, and payment preferences intersect. While Electronics and Sports anchor the revenue story, the Kitchen category's disproportionate return rate signals an area requiring product or fulfillment improvement.

The sharp post-May revenue decline points to a need for targeted promotions or seasonal campaigns to sustain momentum through Q3 and Q4. Credit Card and UPI together account for over 60% of revenue, confirming a predominantly digital payment base worth nurturing through loyalty incentives.

From a portfolio perspective, this project demonstrates proficiency in:
- **End-to-end data pipeline** (raw data → cleaned → modelled → visualized)
- **Advanced DAX** for dynamic KPI measures and return analytics
- **Multi-page dashboard UX** with cross-page navigation and interactive slicers
- **Storytelling with data** to surface actionable business recommendations
